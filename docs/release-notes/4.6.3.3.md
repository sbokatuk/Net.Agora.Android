## What's changed

**`Net.Agora.Signaling.Android` debuts**, at its own version **2.2.6.1**: .NET for Android /
.NET MAUI bindings for
[`io.agora:agora-rtm` 2.2.6](https://central.sonatype.com/artifact/io.agora/agora-rtm) — Agora's
Signaling (RTM 2.x) SDK, under the **`Agora.Rtm`** namespace (matching Agora's own C# / Unity
Signaling naming), self-contained (libaosl ships inside the `.aar`), coexisting with either RTC
package.

```csharp
using Agora.Rtm;

var config = new RtmConfig.Builder("<APP_ID>", "alice").Build();
var client = RtmClient.Create(config);

client.Login(token, resultCallback);
client.Subscribe("lobby", new SubscribeOptions(), resultCallback);
```

Most apps want the cross-platform client instead:
[`Net.Agora.Signaling`](https://github.com/sbokatuk/Net.Agora), which wraps this package and its
iOS sibling behind one awaitable API.

**Releases now publish each package at its own version.** Signaling's 2.2.x native line is what
forces it: no single tag version can be stamped across packages anymore, so `BuildNugets.sh`
packs every package at its own pin from `Directory.Build.props` (`--suffix` for prereleases), a
tag is just the train's label, and a package whose pin did not move since the previous train is
skipped by the push rather than republished. `Net.Agora.Video.Android` and
`Net.Agora.Voice.Android` advance to `4.6.3.3` for that packaging change — their binding surface
is identical to `4.6.3.2`.

> **Package versions are `<native artifact version>.<binding revision>`.** The fourth component
> belongs to this repository and advances when the bindings or packaging change while the native
> artifact stays put.

## Tests

- **Package tests** grew a per-package expectation row — native `.aar` name and size floor, the
  core types a consumer starts with, the namespace-rename prefix that must be left empty, and a
  public-type floor — so the Signaling package is held to the same empty-shell guards as the RTC
  pair, at its own scale (~60 public types against their ~300).
- **Emulator smoke tests** keep their Video and Voice legs; the Signaling package is exercised
  end to end by the [façade repository](https://github.com/sbokatuk/Net.Agora)'s own emulator
  suite, which drives login/publish/subscribe against this packed `.aar`.
