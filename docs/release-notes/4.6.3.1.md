## What's changed

Initial release: .NET for Android / .NET MAUI bindings for Agora's Video (RTC) SDK, generated from
[`io.agora.rtc:full-rtc-basic` 4.6.3](https://central.sonatype.com/artifact/io.agora.rtc/full-rtc-basic)
on Maven Central. Join Agora RTC channels and publish/subscribe audio and video from C#, in a
`net8.0-android`, `net9.0-android` or `net10.0-android` app.

> **Package versions are `<full-rtc-basic version>.<binding revision>`.** `4.6.3.1` is
> full-rtc-basic `4.6.3`, binding revision `1`. The fourth component belongs to this repository and
> advances when the bindings or packaging change while the native artifact stays put.

## Contents

### The binding

The full `class-parse`-generated surface of `full-rtc-basic` — `RtcEngine`, `RtcEngineConfig`,
`IRtcEngineEventHandler`, `ChannelMediaOptions`, `VideoCanvas` and roughly 300 more public types —
under the **`Agora.Rtc`** namespace, renamed from the Java package `io.agora.rtc2` to match Agora's
own C# / Unity SDK naming, so consumers coming from that surface find the API in the expected
place.

```csharp
using Agora.Rtc;

var config = new RtcEngineConfig { MContext = context, MAppId = "<APP_ID>" };
var engine = RtcEngine.Create(config);

engine.EnableVideo();
engine.JoinChannel(token: null, channelId: "my-channel", optionalInfo: null, uid: 0);
```

**`full-rtc-basic`, deliberately not `full-sdk`.** The umbrella artifact is a POM-only aggregator
over roughly twenty optional plugin `.aar`s (AI noise suppression, face detection, virtual
background, screen sharing, …); binding it pulls in features this package exposes no API for, and
Java dependency verification (`XA4241`) refuses to build unless every plugin is present too.
`full-rtc-basic` is Agora's own base artifact, with exactly one dependency (`io.agora.infra:aosl`),
which the package also carries.

Most apps want the cross-platform client instead:
[`Net.Agora.Video`](https://github.com/sbokatuk/Net.Agora), which wraps this package and its iOS
sibling behind one API. Reach for this package directly only when you need something the
cross-platform client does not expose.

## Tests

Everything runs against the packed package, not the build output — the failure mode worth catching
here is a packaging one, most importantly the net8 "empty shell" trap where `@(AndroidMavenLibrary)`
is silently ignored and the build succeeds with a few-KB binding assembly and no `.aar`.

- **Package tests** assert the layout (a real binding assembly and the native `.aar`s for every
  target framework) and, through the metadata reader, the API itself: the core `Agora.Rtc` types
  exist, the `IO.Agora.Rtc2 → Agora.Rtc` rename left nothing behind, and `RtcEngine` still exposes
  the channel lifecycle entry points.
- **Emulator smoke tests** install a device-test app built against the packed package on an Android
  emulator and drive the raw binding: resolve the Java entry points from the packaged `.aar`, read
  the native SDK version, create the engine, enable/disable video and audio, run the local camera
  preview, destroy the engine. No Agora credentials are involved — the App ID is syntactically
  valid but unregistered, which is enough for everything short of joining a channel. The e2e runs
  on the two extreme target frameworks, `net8.0-android34.0` and `net10.0-android36.0`.

## Sample

`samples/Net.Agora.Sample.Android` is a MAUI app built straight against this package — an App ID
entry, camera/microphone permission handling, and a local camera preview rendered into a
`SurfaceView` behind a small MAUI handler. The full join/publish/subscribe flow lives in the façade
repository's sample.
