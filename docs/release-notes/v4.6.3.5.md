## What's changed

`Net.Agora.Video.Android`, `Net.Agora.Voice.Android` and the twelve `Net.Agora.Extensions.*.Android`
packages advance to **4.6.3.5**. The native SDK is unchanged at `io.agora.rtc:*` 4.6.3; what changed
is the C# surface and the packaging.

### `RtcEngine` raises C# events

The binding still generates `IRtcEngineEventHandler` as Java declares it — an abstract class with 93
virtual methods — but the ten callbacks an app actually starts with are now events on the engine:

```csharp
engine.UserJoined += (_, e) => Attach(e.Uid);
engine.ConnectionStateChanged += (_, e) => Log(e.State, e.Reason);
engine.Error += (_, e) => Log(e.ErrorCode);
```

`JoinChannelSuccess`, `LeftChannel`, `UserJoined`, `UserOffline`, `Error`, `UserMuteAudio`,
`UserMuteVideo`, `AudioVolumeIndication`, `TokenPrivilegeWillExpire`, `ConnectionStateChanged`. A
dispatcher is installed once through the SDK's own `addHandler` on first subscription and is rooted
by the engine, which also removes the lifetime trap a hand-written handler has — a handler that gets
collected stops delivering callbacks with no error.

Named `LeftChannel` rather than `LeaveChannel` because `RtcEngine.LeaveChannel()` is a method and
C# does not allow both. Every event and its `EventArgs` carries XML documentation, including which
native callback feeds it and the reminder that the SDK raises them on its own thread.

Subclassing `IRtcEngineEventHandler` still works and is still the way to reach the other 83
callbacks; the two styles compose, since the dispatcher is just another registered handler.

### The samples no longer need a handler subclass

`samples/Net.Agora.Sample.Android` and `.Voice.Android` dropped their `EngineHandler` classes for
event subscriptions.

### Packaging: the payload is no longer shipped twice

On `net10.0-android36.0` these packages carried both the Maven artifact and a project-generated
`.aar` holding a second copy of the same `.so` files. `Net.Agora.Extensions.SpatialAudio.Android`
drops from 47 MB to 36 MB and `Net.Agora.Video.Android` from 203 MB to 192 MB — the latter
mattering because nuget.org's hard limit is 250 MB. It also clears an XA4301 duplicate-`libaosl.so`
warning that consuming apps were emitting.

### Supply chain: artifacts are pinned by digest

`build/checksums.txt` records a SHA-256 for all 21 native coordinates and
`build/verify-artifacts.sh` checks them against what the repositories serve; the pack job runs it.
A Maven coordinate is a mutable pointer, `AndroidMavenLibrary` performs no content check, and the
JitPack-built netless artifacts are rebuilt from git tags that have moved before.
